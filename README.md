# Sentient 2.0

[View the website](https://chatgptricks.github.io/sentient-2.0/)

The website source is in [`site/`](site/). See the [development guide](site/README.md) for local setup, animation details, and deployment behavior.

```sh
cd site
npm ci
npm run dev
```

Pushes to `main` run the site checks and publish to GitHub Pages. The public contact form is disabled until a production inquiry backend is connected.
